# FieldNote

A minimalist, privacy-focused productivity app for notes, tasks, and thoughtful planning.

## Overview

FieldNote brings everyday productivity into one calm workspace with:

- Daily task management
- Rich notes
- Calendar timeline
- Encrypted storage
- AI Copilot scheduling assistance

The AI Copilot is designed to help turn plans into practical schedules while keeping the experience simple and focused.

## Tech Stack

- Kotlin
- Android
- Gemini AI integration
- Encrypted local storage

## Project Status

Active development. Features and implementation details may evolve as the project grows.
